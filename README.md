BUILDWISE — Final Website Prototype

HOW TO OPEN (Windows)
1. Extract BUILDWISE_Final.zip.
2. Open the extracted BUILDWISE_Final folder.
3. Double-click index.html. It opens in Chrome.
4. Enter building information and click "Create / update profile".
5. Optional: enter monthly electricity values or click "Fill illustrative example".
6. Choose a what-if measure, adjust the assumed reduction/cost/tariff/emission factor, and click "Run what-if simulation".
7. Click "Export summary (.txt)" to save a report summary.

FILES
- index.html: page structure and sections
- style.css: responsive visual design
- script.js: profile validation, EPI, chart, scenario calculations, and text export
